# Nexora — SaaS Product Landing Page

A responsive SaaS landing page portfolio project built with React, Vite, Framer Motion, Lucide React, and custom CSS.

## Features
- Responsive navigation with mobile menu
- Hero section with animated product dashboard preview
- Feature cards and workflow section
- Product highlight section
- Pricing cards
- Testimonial section
- Interactive FAQ accordion
- Framer Motion entrance, hover, and floating animations
- Responsive layouts for mobile, tablet, and desktop

## Requirements
- Node.js (LTS recommended)
- VS Code (or another code editor)

## Run locally
1. Extract the project ZIP.
2. Open the extracted `nexora-landing` folder in VS Code.
3. Open Terminal in VS Code.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Production build
Run `npm run build`. Vite creates the production-ready site in the `dist` folder.

## Notes
Nexora is a fictional SaaS brand created for a frontend portfolio assignment. Pricing, testimonials, and dashboard data are illustrative only. No real authentication, payments, or backend services are connected.
